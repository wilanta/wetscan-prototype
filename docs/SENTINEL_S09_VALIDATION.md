## Incident during validation (disclosed)

While trying to obtain a base-master comparison for the default-timeout demo regression, I created a git worktree of `master@e59b03c` and junctioned its `node_modules` to the main checkout's. `git worktree remove --force` then followed the junction and **deleted the contents of the main checkout's `node_modules`** (regenerable dependencies only; no source, data, database or git state was affected). I restored it with `npm ci` from the unchanged `package-lock.json` (576 packages; lockfile unmodified) and **re-ran every gate above after the restore** (typecheck, lint, 1692 unit tests, build, PostgreSQL and browser suites). The baseline comparison was abandoned.
