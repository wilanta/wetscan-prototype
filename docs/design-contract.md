# WetScan prototype design contract

The product brief in the repository governs scope. This is a fictional security workspace, with Canvas as the spatial explanation of an application. Primary action: inspect Orders API, follow FIND-102, then simulate and verify a Sentinel incident.

Visual direction: quiet operational interface, white surfaces, cool slate background, restrained indigo, dark ink, generous spacing, compact navigation. A custom connected-node application map is the memorable element. Severity always has text. Provenance always identifies the fixture boundary. Default light; complete dark theme.

Viewports: 1440x900, 1280x900, 390x844. Mobile has a component list and collapsible navigation. Use semantic links/buttons, visible focus, accessible Radix dialogs, reduced motion and labeled inputs.

States: route skeleton for loading; empty filters/incidents with recovery; invalid staging input with validation; runtime coverage explicitly partial; saves/simulated jobs with visible feedback; real OAuth and AI unavailable with explained permission/configuration boundaries. No production traffic or provider calls.

References: local authoritative blueprint; approved connected WetScan document read successfully. Reference folder discovered successfully; image inspection is recorded separately if completed.
