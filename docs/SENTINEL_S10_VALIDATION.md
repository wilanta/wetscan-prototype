## Defects found and fixed during S10

1. Six live views each hard-coded a different tab list (Responses/Notifications/Reports missing in some) and none highlighted the active tab (`aria-current` without the `active` class the CSS needs) → one shared `LiveSentinelNav`.
2. Real-project chrome pointed MANAGE → Notifications/Reports at the demo pages, showed the **demo preview count** on the bell and a demo "Reset demo" button → project-aware chrome; Integrations/Guard badged DEMO.
3. A storage-not-configured environment would have shown CAN-008 as "failed"; the existing contract (and E2E) say "Monitoring not connected" → adapter maps `telemetry_not_configured`/`migration_not_ready` to `not_monitored`.
